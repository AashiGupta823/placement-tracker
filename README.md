# 📋 Placement Tracker + Resume Analyzer

A full-stack web application to track job applications during placement season with an AI-powered resume analyzer.

## 🚀 Live Demo
Coming soon...

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, REST API, Maven
- **Database:** MySQL, Spring Data JPA
- **Frontend:** HTML, CSS, JavaScript
- **AI Feature:** NLP-based Resume Analyzer (Apache PDFBox)

## ✨ Features
- Add and track job applications
- Update application status (Applied/Interview/Offer/Rejected)
- Dashboard with live stats
- Upload resume PDF for each application
- AI Resume Analyzer — match score against job description

## 🔧 How to Run Locally
1. Clone the repo
2. Setup MySQL database named `placement_db`
3. Update `application.properties` with your MySQL password
4. Run `mvnw.cmd spring-boot:run`
5. Open `http://localhost:8080`
